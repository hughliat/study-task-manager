# 学有计划 · 学习任务管理器

一个适合初学者阅读和继续迭代的中文学习任务管理器。零第三方依赖，数据保存在当前浏览器中。

## 功能

- 添加、编辑和删除任务；删除前确认。
- 标记完成或恢复为待完成。
- 按全部、待完成、已完成筛选，搜索任务名称或学科。
- 设置学科、截止日期和优先级，查看进度与逾期数量。
- 自动保存到 localStorage，刷新后恢复。
- 手机与桌面布局，键盘可操作的输入和按钮。
- 保存失败会提示；损坏数据不会被静默覆盖。

## 本地运行

需要 Node.js 20 或更新版本；无需 `npm install`。

在项目目录打开终端：

```sh
npm start
```

访问 http://127.0.0.1:4178。终端按 Ctrl+C 停止服务。
请通过本地服务访问，不要直接双击 HTML，浏览器 ES 模块需要 HTTP 环境。

默认端口被占用时，在 PowerShell 中使用：

```powershell
$env:PORT = '4179'
npm start
```

保持相同地址与端口可以继续读取同一份本地数据。换浏览器、浏览器配置文件、地址或端口会使用另一份存储。

## 存储与限制

数据仅保存于当前浏览器的 `study-task-manager:v1` localStorage 项；不上传服务器，不跨设备同步。
清除网站数据会删除任务。第一版不提供账号、云同步、通知和数据导入导出。
日期用于提醒标记，不会主动弹出系统通知。服务监听 127.0.0.1，仅本机访问。

## 用 Qoder 继续开发

把本目录作为 Qoder 项目目录，在新任务中使用 `programming-squad:start-squad`。
例如：在不引入后端的前提下添加任务 JSON 导出与导入，补齐校验和测试；先读取 AGENTS.md。

## 发布到 GitHub

目前尚未创建远端仓库或推送。发布前确定仓库名和公开/私有选择，核对拟提交文件并再次运行测试。
使用已经配置的 `programming-squad:github-release` 技能，或手动通过 Git 发布。
GitHub 代码仓库不等于在线网站；需要 GitHub Pages 时另行配置并验证静态路径。

本项目未指定开源许可证；公开发布前可按自己的意愿选择许可证。
