# 开发设计

## 模块

`src/tasks.js`：创建、校验、不可变更新、筛选、统计和存储解析。
`src/app.js`：事件处理、表单编辑状态、DOM 安全呈现和 localStorage。
`server.js`：固定文件白名单，GET/HEAD；不暴露项目文档、源码外文件或目录。

## 数据

任务字段：id、title、subject、dueDate、priority、completed、createdAt。
日期为 YYYY-MM-DD，用本地日历日判断逾期。ID 使用浏览器 crypto.randomUUID。
localStorage 键：study-task-manager:v1，值为任务数组 JSON。

## 运行

`npm start` 启动本机 4178 端口；`npm test` 使用 Node 内置测试；无需安装依赖或构建。

## 风险处理

用户文本只通过 textContent 写入页面。数据加载失败时阻止编辑以保留原值。
写入存储失败时不更新任务集合。浏览器存储不是备份，清除网站数据会丢失任务。
