# MVP 需求与验收标准

| 编号 | 功能 | 验收标准 |
| --- | --- | --- |
| P0-1 | 创建 | 输入非空名称后出现任务；学科、日期可选；优先级有三档 |
| P0-2 | 编辑 | 修改指定任务后保留 ID、创建时间与完成状态；取消不修改任务 |
| P0-3 | 删除 | 确认后仅移除指定任务；取消后任务保留 |
| P0-4 | 完成 | 勾选后任务完成，可恢复；进度随之变化 |
| P0-5 | 筛选和搜索 | 状态与关键词共同作用，支持任务标题和学科 |
| P0-6 | 本地持久化 | 刷新后任务与完成状态保留；写入失败提示且不伪装保存 |
| P1-1 | 截止与进度 | 截止当天不算逾期；已完成不算逾期；空列表进度为 0 |
| P1-2 | 适配 | 手机无需横向滚动，输入与按钮可通过键盘操作 |

第一版不包含注册登录、跨设备同步、后台提醒或在线部署。
